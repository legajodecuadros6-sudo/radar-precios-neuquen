# Instrucciones para agentes de Radar de Precios

Antes de trabajar, leé `agent_memory/REGLAS_TRABAJO.md` y el último
`agent_memory/HANDOFF.md`. Las reglas se aplican a OpenCode con GLM,
Antigravity, Cursor y cualquier otro agente. Si la herramienta no carga
AGENTS.md automáticamente, abrí estos documentos al iniciar la sesión.
